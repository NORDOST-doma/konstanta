# Сайт УК ООО «Константа» (GitHub Pages)

Сборка для публикации на GitHub Pages или любом статическом хостинге.

## Особенности сборки:
1. **Интерактивная карта 2ГИС:** подключен чистый движок 2ГИС без рекламы, с охватом всех объектов компании и отключенным зумом колесиком мыши.
2. **100% соответствие 152-ФЗ:** форма обратной связи работает без передачи персональных данных по сети с локальной обработкой в браузере.
3. **Автономная панель администратора (`admin.html`):** все изменения сохраняются в `localStorage` браузера и мгновенно отображаются на страницах сайта без необходимости в серверной части.
4. **Функции админки:** кнопки «Сбросить к исходным» и «Скачать config.json».
5. **Относительные пути:** сайт корректно открывается из любой подпапки.

## Публикация на GitHub Pages:
Ветка `gh-pages` настроена для автоматической публикации.
Адрес сайта: https://nordost-doma.github.io/konstanta/
