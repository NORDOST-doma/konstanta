# Демо-версия сайта УК ООО «Константа» (GitHub Pages)

Статическая демонстрационная сборка для публикации на GitHub Pages или любом статическом хостинге.

## Особенности демо-сборки:
1. **100% соответствие 152-ФЗ:** форма обратной связи работает локально в браузере без передачи персональных данных по сети. После проверки выводится сообщение об успешной регистрации.
2. **Автономная панель администратора (`admin.html`):** все изменения сохраняются в `localStorage` браузера и мгновенно отображаются на страницах сайта без необходимости в серверной части.
3. **Функции админки в демо:** кнопки «Сбросить к исходным» и «Скачать config.json».
4. **Интерактивная карта 2ГИС:** подключен чистый движок 2ГИС без рекламы, с охватом всех объектов компании и отключенным зумом колесиком мыши.
5. **Относительные пути:** сайт корректно открывается из любой подпапки (например, `https://username.github.io/repository/`).

## Публикация на GitHub Pages:
1. Загрузите содержимое папки `dist-github` в ветку `gh-pages` (или в папку `docs/` ветки `main`).
2. В настройках репозитория GitHub перейдите в **Settings** -> **Pages** и выберите источник публикации.
