# Сайт УК ООО «Константа» (Production-сборка)

Боевая версия сайта с полноценным Node.js / Express бэкендом, API панели администратора, отправкой заявок через Nodemailer и интерактивной картой 2ГИС.

## Быстрый запуск

1. Установите зависимости:
   ```bash
   npm install --production
   ```
2. Настройте файл `.env` (образец в `.env.example`).
3. Запустите сервер:
   ```bash
   npm start
   ```
4. Откройте в браузере:
   - Главная страница: `http://localhost:3000`
   - Панель управления: `http://localhost:3000/admin`

Подробная инструкция по развертыванию на VPS / хостинге: см. `ИНСТРУКЦИЯ_ПО_РАЗВЕРТЫВАНИЮ.md`.
