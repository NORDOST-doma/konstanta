# Подробная пошаговая инструкция по запуску сайта УК «Константа»

---

## 1. Настройка почты для приёма заявок с формы

Все заявки, отправленные через сайт, автоматически и гарантированно сохраняются во внутренний журнал `data/inquiries.json` и сразу доступны во вкладке «Заявки с сайта» в админ-панели (`/admin`).

Чтобы заявки также дублировались письмом на вашу личную почту:
1. В корневой папке проекта создайте или откройте файл `.env` (образец есть в `.env.example`).
2. Заполните реквизиты вашего почтового ящика:

```env
PORT=3000

# Хост SMTP вашего почтового провайдера:
# Для Яндекс: smtp.yandex.ru
# Для Mail.ru: smtp.mail.ru
# Для Gmail: smtp.gmail.com
SMTP_HOST=smtp.yandex.ru
SMTP_PORT=465
SMTP_SECURE=true

# Ваш логин/почта отправителя:
SMTP_USER=info@konstanta-uk.ru

# Специальный «Пароль приложения» (генерируется в настройках безопасности почты Яндекс/Mail.ru):
SMTP_PASS=ваш_пароль_приложения

# Адрес почты, на который будут приходить уведомления о новых заявках:
NOTIFICATION_EMAIL=director@konstanta-uk.ru
```

> **Важно:** современные почтовые сервисы (Яндекс, Mail.ru, Google) требуют создавать «Пароль для внешних приложений» в разделе безопасности почты вместо основного пароля от аккаунта.

## 2. Размещение сайта на хостинге

### Вариант А: Обычный хостинг с поддержкой Node.js (Beget, Timeweb, Reg.ru и др.)
1. В панели управления хостинга перейдите в раздел **Сайты** / **Node.js**.
2. Создайте сайт и выберите версию Node.js `18` или `20+`.
3. Укажите точку входа: `server.js`.
4. Загрузите файлы из архива в корневую директорию сайта (через файловый менеджер хостинга или FTP/SFTP).
5. В панели хостинга нажмите кнопку **«Установить зависимости»** (или в терминале выполните `npm install`).
6. Запустите сайт кнопкой «Запустить» / «Restart».

---

### Вариант Б: Виртуальный сервер (VPS / VDS — Ubuntu / Debian)
1. Подключитесь к серверу по SSH:
   ```bash
   ssh root@ip-вашего-сервера
   ```
2. Установите Node.js (если не установлен):
   ```bash
   curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
   sudo apt-get install -y nodejs unzip
   ```
3. Распакуйте архив в директорию веб-сервера (например `/var/www/konstanta-site`):
   ```bash
   mkdir -p /var/www/konstanta-site
   unzip konstanta-site.zip -d /var/www/konstanta-site
   cd /var/www/konstanta-site
   npm install --production
   ```
4. Для непрерывной работы в фоновом режиме используйте менеджер процессов `pm2` или `systemd`:
   ```bash
   # Установка pm2
   sudo npm install -g pm2
   pm2 start server.js --name konstanta
   pm2 save
   pm2 startup
   ```

## 3. Привязка собственного домена

1. Зайдите в панель управления регистратора вашего домена (Reg.ru, Beget, Nic.ru и др.).
2. Откройте раздел **«Управление DNS»** / **«Ресурсные записи»**.
3. Добавьте запись типа **A**:
   - **Имя / Хост:** `@` (или оставьте пустым)
   - **Значение / IP:** IP-адрес вашего сервера (например, `31.77.251.96`)
4. Добавьте запись для поддомена `www`:
   - **Тип:** `A`
   - **Имя / Хост:** `www`
   - **Значение / IP:** IP-адрес вашего сервера
5. Изменения вступают в силу в течение 15 минут — 2 часов.
6. Для бесплатного подключения защищенного сертификата HTTPS (SSL) выполните на сервере:
   ```bash
   sudo apt-get install -y certbot python3-certbot-nginx
   sudo certbot --nginx -d ваш-домен.ru -d www.ваш-домен.ru
   ```

## 4. Панель управления (Админка)

Панель администрирования доступна по адресу:
`http://ваш-домен.ru/admin` (или `admin.html`)

В ней вы можете в визуальном режиме без правок кода:
- Добавлять, редактировать и удалять обслуживаемые **Объекты**
- Управлять перечнем **Услуг**
- Редактировать карточки **Сотрудников**
- Обновлять фотографии в **Галерее**
- Публиковать **Новости и объявления**
- Менять телефоны, адреса и реквизиты в **Контактах**
- Просматривать и очищать поступающие **Заявки с сайта**
