# Сайт управляющей компании ООО «Константа»

## Быстрый запуск
1. Установка зависимостей:
   ```bash
   npm install
   ```
2. Запуск локального сервера:
   ```bash
   npm start
   ```
   Сайт откроется по адресу `http://localhost:3000`.
3. Визуальная панель администратора:
   `http://localhost:3000/admin`

## Пошаговая инструкция по развертыванию
Подробное руководство по выгрузке на хостинг, привязке домена и настройке почты для заявок находится в файле:
`ИНСТРУКЦИЯ_ПО_РАЗВЕРТЫВАНИЮ.md`
